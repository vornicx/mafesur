# MAFESUR — Archic Flagship Concept

Concepto de rediseño integral para Automóviles Mafesur, construido como proyecto multipágina real y orientado a conversión.

## Qué incluye

- Home editorial automotriz
- Exposición de vehículos con filtros
- Fichas individuales con galería, especificaciones y CTA de WhatsApp
- Página de taller y solicitud de cita conceptual
- Alquiler de turismos, furgonetas y autocaravanas
- Tarifas de autocaravanas
- Historia y posicionamiento de la empresa
- Contacto
- Panel interno conceptual de stock, oportunidades y citas
- Responsive y layouts específicos para móvil

## Ejecutar

```bash
npm run build
npm run dev
```

Abrir `http://localhost:4173`.

## Nota de assets e inventario

Las imágenes visibles del concepto se sirven desde recursos públicos oficiales de Mafesur. El inventario de la demo es una selección curada para presentar la experiencia y no debe interpretarse como una sincronización en tiempo real del stock. Antes de una entrega final/producción se conectaría el inventario real, sus fotografías, kilometraje, equipamiento, disponibilidad y precios.

## Estado

Prototipo comercial / concepto Archic. Los formularios y el panel muestran la experiencia objetivo; para producción deben conectarse a base de datos, autenticación, WhatsApp/email y gestión real del inventario.
